# Google Sheets 연동 구조

## 목표

GitHub Pages에서 제공하는 일정 화면이 Google Spreadsheet의 팀원 정보를 읽어 좌측 팀원 영역에 표시한다. 팀원은 GitHub 또는 Google 계정으로 로그인하지 않고, 이름이나 비밀번호도 입력하지 않는다.

## 구성

```text
GitHub Pages의 React 앱
        │
        │ HTTPS
        ▼
Google Apps Script Web App
        │
        ▼
Google Spreadsheet
```

브라우저는 스프레드시트에 직접 접근하지 않는다. Apps Script가 공개 가능한 팀원 데이터만 읽어 JSON으로 반환한다.

## 현재 구현 범위

- 스프레드시트에서 활성 팀원과 현재 주의 가능 시간을 함께 읽는다.
- 팀원 목록, 일정 히트맵과 추천 시간을 API 데이터로 표시한다.
- 팀원별 일정을 30분 단위로 편집하고 저장한다.
- 로딩, 빈 목록, 조회 실패와 저장 실패 상태를 표시한다.

실제 배포 URL은 커밋하지 않고 `VITE_MEMBERS_API_URL` 환경 변수로 주입한다.

## 팀원 데이터 계약

실제 스프레드시트 구조를 확인한 뒤 기존 열을 아래 필드에 매핑한다.

| 필드 | 필수 | 설명 |
| --- | --- | --- |
| `member_id` | 예 | 이름 변경과 무관한 팀원 식별자 |
| `display_name` | 예 | 화면에 표시할 이름 |
| `server` | 예 | 이름 뒤에 `@`와 함께 표시할 서버명 |
| `position` | 예 | `MT`, `ST`, `MH`, `SH`, `D1`, `D2`, `D3`, `D4` 중 하나. 이 순서로 화면에 표시 |
| `active` | 예 | 현재 목록 포함 여부 |
| `status` | 아니요 | 일정 입력 상태. 1단계에서는 기존 값 또는 `미입력` 사용 |
| `updated_at` | 아니요 | 최근 일정 수정 시각 |

Apps Script 응답 형식은 다음과 같이 고정한다.

```json
{
  "members": [
    {
      "id": "member-001",
      "name": "김철수",
      "server": "루페온",
      "position": "MT",
      "status": "입력 완료",
      "updatedAt": "2026-09-15T10:24:00+09:00"
    }
  ]
}
```

## 설정값

프론트엔드는 Apps Script 배포 URL을 다음 환경 변수로 받는다.

```text
VITE_MEMBERS_API_URL=https://script.google.com/macros/s/.../exec
```

이 URL은 API 위치이며 인증 비밀값으로 사용하지 않는다. 서비스 계정 키, OAuth 비밀값 또는 스프레드시트 편집 권한은 프론트엔드 환경 변수에 넣지 않는다.

## 주간 데이터 원칙

후속 단계에서 백엔드는 `Asia/Seoul` 기준 현재 날짜가 속한 월요일을 `week_start`로 계산한다. 새로운 주가 시작되면 새로운 `week_start` 데이터를 조회하므로 기존 주간 데이터를 삭제하거나 초기화할 필요가 없다.

## 인증 없는 편집의 한계

로그인과 본인 확인이 없으면 서버는 실제 사용자가 누구인지 판별할 수 없다. 일정 편집을 연결하는 단계에서는 페이지 주소를 아는 사람이 다른 팀원의 일정도 수정할 수 있다는 점을 운영 정책으로 수용하거나, 별도 입력이 필요 없는 팀원별 전용 편집 링크를 도입해야 한다.

## 단계별 진행

1. 실제 스프레드시트의 탭 이름과 헤더를 확인한다.
2. 팀원 조회용 Apps Script를 작성하고 Web App으로 배포한다. 완료
3. React 앱에 팀원 repository와 로딩·오류 상태를 구현한다.
4. 실제 배포 URL로 좌측 팀원 목록을 검증한다.
5. 주차 계산과 일정 조회를 연결한다. 주간 범위, 기존 선택 복원과 실제 인원 집계 완료
6. 일정 저장과 동시 수정 방지를 연결한다. Apps Script와 프론트엔드 구현 완료, 배포 검증 대기
7. GitHub Actions와 GitHub Pages 배포를 구성한다. 로컬 워크플로 작성 완료, GitHub 설정 및 배포 대기

추천 시간은 활성 팀원 전원이 가능한 구간과 2명 이상이면서 전원 미만인 구간으로 나눈다. 같은 날짜에 같은 인원수가 연속되는 30분 슬롯은 하나의 구간으로 병합하며, 부분 중첩 구간은 가능 인원 내림차순으로 표시한다.

Apps Script 원본은 `apps-script/Code.gs`에서 관리한다. `active` 열은 대소문자와 공백을 무시하고 `TRUE`, `1`, `YES`, `Y`를 활성 값으로 처리한다. `FALSE`, `0`, `NO`, `N`과 그 밖의 값은 비활성으로 처리한다.

`availability`의 시간 헤더는 Google Sheets가 시간 값으로 자동 변환할 수 있다. Apps Script는 문자열, 날짜 또는 숫자 형태의 시간 헤더를 `HH:mm`으로 정규화한 뒤 이름으로 열을 찾는다. 따라서 시간 열의 표시 형식이나 순서를 바꿔도 데이터가 다른 시간에 기록되지 않는다.
